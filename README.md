# NLP_Experiments

This repository contains implementations of **Natural Language Processing (NLP) experiments** based on the DBATU practical syllabus. The experiments cover fundamental and advanced NLP techniques including text processing, language models, POS tagging, Named Entity Recognition, text classification, sentiment analysis, and deep learning-based sequence models.

## Experiments

1. **Tokenization and Word Frequency** — Convert text into tokens and find word frequency.
2. **WordNet** — Find synonyms and antonyms of a word using WordNet.
3. **Bigrams, Trigrams & Regular Expressions** — Demonstrate language models and generate regular expressions for given text.
4. **Lemmatization, Stemming & POS Tagging** — Perform text normalization and identify parts of speech using the Penn Treebank tag set.
5. **HMM POS Tagging & Chunking** — Implement Hidden Markov Model (HMM) for POS tagging and build a chunker.
6. **Named Entity Recognition** — Identify and extract named entities from text.
7. **Semantic Role Labelling** — Identify semantic roles and named entities in sentences.
8. **Text Classification using Logistic Regression** — Build a text classifier using the Logistic Regression model.
9. **Movie Review Sentiment Classification** — Classify movie reviews based on their sentiment.
10. **RNN for Sequence Labelling** — Implement a Recurrent Neural Network for sequence labelling.
11. **POS Tagging using LSTM** — Implement Part-of-Speech tagging using an LSTM network.
12. **Word Sense Disambiguation** — Implement word sense disambiguation using LSTM/GRU.
